Conversion tab cannot decode a valid empty blueprint book

1. Load `repro.zip`. Admin → Conversion already contains an empty blueprint-book export in Encoded Text.
2. Click Decode ==>.

From a new game: Create an empty blueprint book in Factorio and export it. Paste the string into Helmod Admin → Conversion → Encoded Text and click Decode ==>. The attached string was generated by the game using `LuaItemStack.export_stack`, not hand-written JSON.

Expected: A valid empty book should decode with empty entity and tile lists.

Cause: Factorio omits `blueprint_book.blueprints` for an empty book. `Blueprint.get_entities` iterates it without a nil guard. `get_tiles` has the same assumption at line 45, but the entity path fails first.

Recovery: Use a book containing a blueprint; the empty-book case needs a guard.
